# Game selection logos

These logos ship with the application so they display before a game pack is installed.

- `minecraft.png`: original Minecraft 1.7.10 title texture from `assets/minecraft/textures/gui/title/minecraft.png` in the client archive. The component joins its two sprite rows for display.
- `gtnh.png`: GT: New Horizons logo from the 2.8.4 instance's `minecraft/config/txloader/load/mainmenu/textures/logo2.png`.

Artwork belongs to Mojang and the GT: New Horizons team respectively.
